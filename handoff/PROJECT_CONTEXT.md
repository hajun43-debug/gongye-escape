- 게임: https://hajun43-debug.github.io/gongye-escape/
- Pages 설정: `main`, 최상위 `/`, `.nojekyll`, 별도 빌드 없음.

- 인수인계 전 기준 커밋: `91ac951909df9d987c9d3f94732fc850fe778708`. 이후 인수인계 파일과 배포 도구를 추가한다. 최신 코드는 GitHub `main`과 Git 이력을 기준으로 확인한다.

## 파일과 실행

`index.html`과 `style.css`는 학생 화면, `scene.js`는 절차적으로 만든 네 3D 작업실, `game.js`는 상태·단서·퍼즐·저장·결말이다. `vendor/three.min.js`는 Three.js r128이며 MIT 라이선스가 동봉돼 있다. 외부 이미지·글꼴·CDN·AI API를 호출하지 않는다.

`teacher.html`과 `teacher.js`는 별도 교사용 화면이다. `docs/`에는 교사용 설명서, 정답 없는 학생 워크시트, 원본 분석과 테스트 결과가 있다. `tests/browser-tests.html`은 실제 게임 iframe을 조작하는 통합 검증 페이지다.

로컬 서버: `node server.cjs`, 주소 http://127.0.0.1:4173/ . 서버는 로컬 컴퓨터에만 연결된다. 다른 기기에서 이 주소로 접속하는 기능은 없다. 학교 태블릿에는 공개 Pages 주소를 안내하면 된다.

## 네 퍼즐

1. **한지 / 종이의 방 → 3**: 편지·닥 섬유·종이 뜨는 발을 조사한 뒤 두 투명지를 각각 직접 옮겨 같은 빛판 틀에 겹친다. 분할 무늬의 중첩으로 실제 숫자 3이 나타난다. 재료와 성질 확인 문항까지 맞춰야 완료다. 축소할 때 무늬가 사라지지 않도록 `image-rendering: pixelated`를 유지한다.
2. **전통 매듭 / 실의 방 → 4**: 두 경로 손잡이를 좌우 말뚝에 옮기고 좌상부터 시계 방향으로 적색 위·금빛 위·적색 위·금빛 위를 맞춘다. 경로와 네 교차를 모두 검사한다. 단순 8자 고리 두 개 방식이 아니다. 교육 도식과 실제 국화매듭·가락지매듭 제작법을 구별한다.
3. **상감청자 / 흙의 방 → 2**: 성형 → 무늬 홈 새기기 → 다른 색 흙 채우기 → 표면 정리하기 카드를 직접 끌어 정렬한다. 다음 체험에서 꽃 홈 3곳은 백토, 줄기 홈 3곳은 흑토로 채운다. 실제 제작에는 건조·초벌·유약·재벌 등 추가 공정이 있다고 안내한다.
4. **나전칠기 / 빛의 방 → 6**: 여섯 자개 꽃잎을 이동·회전하여 실제 꽃을 만든다. 번호와 관계없이 방향이 맞는 빈자리에 놓을 수 있다. 위치와 각도가 모두 맞아야 고정되며, 마지막에 꽃잎 수 6을 입력한다. 꽃잎 수는 게임 규칙이고 자개는 빛을 반사한다.

마지막 자물쇠는 **종이 → 실 → 흙 → 빛**, **3426**이다. 숫자를 미리 알아도 네 방을 완료하기 전에는 탈출할 수 없다.

## 공통 기능과 저장

모둠 이름, 이야기, 360도 마우스·한 손가락 탐색, 투영 단서 표식과 조사 목록, 방별 미션, 오답 피드백, 방마다 세 단계 힌트, 타이머, Web Audio 효과음, 복원 수첩, 결말과 학습 요약, 이어 하기·초기화를 구현했다. 네 방은 처음부터 자유롭게 이동하여 순환 수업을 지원한다.

학생 키는 `artisan-seals-v1`, 교사 연습 키는 `artisan-seals-practice-v1`이다. 같은 브라우저·주소의 localStorage에만 저장한다. 창이 숨겨진 시간은 타이머에 더하지 않는다. 조작 중간 위치·순서·색 흙·회전도 저장한다. 카메라 방향은 저장하지 않는다.

교사용 연습은 `?practice=1&room=0`(0~3)으로 출발한다. 교사 화면의 입장 코드는 **1031**이며, 정답 노출을 줄이는 UI 분리용이지 보안 인증이 아니다. 연습 탭을 닫은 뒤 선택 방 초기화를 수행한다.

## 검증 범위와 제한

공개 사이트에서 합성 mouse/touch PointerEvent로 실제 SVG 조작을 수행하고, 정답·오답·저장·이어 하기·초기화·3426 탈출·교사 기록 분리·세 화면 크기를 검사해 56개가 통과했다. 실제 마우스 드래그와 네 작업실의 화면도 확인했다. 실물 태블릿·Safari·실제 20명 학급 운영의 실증은 남아 있다.

3D는 교육용 절차 모델이며 정밀 유물 복제는 아니다. 자료는 출력용 HTML이고 별도 PDF나 프린터 실기 검증은 없다. 자동 저장은 기기 간 공유되지 않는다. 파일 더블클릭은 내장 브라우저의 URL 정책 때문에 검증하지 못했고 HTTP 실행을 검증했다.

## 결정과 배포 이력

사용자는 기획서만 만드는 대신 실행되는 게임·교사 자료·워크시트·ZIP과 실제 테스트를 요구했다. GitHub 배포를 요청하여 코드를 업로드했다. 처음 저장소 이름은 `-`였으며, 나중에 사용자가 한글 ‘공예방탈출’을 원했다. GitHub의 ASCII 이름 제한을 설명한 뒤 사용자가 **gongye-escape**를 선택하여 변경하고 재배포했다.

초기 Windows 브라우저 자동 제어는 주소 확인 문제로 설정을 끝내지 못했다. 이후 사용자의 요청으로 GitHub CLI를 설치했고 사용자가 공식 브라우저 인증을 직접 완료했다. CLI로 코드 업로드와 Pages 배포를 완료했다. 이 컴퓨터에서 설치·인증된 CLI 상태는 새 컴퓨터의 로그인 상태를 보장하지 않는다.

이번 요청은 다른 컴퓨터의 새 GPT에서도 대화 맥락과 프로그램을 이어 쓰게 하는 것이다. 사용자는 **비공개 GitHub + ZIP** 방식을 선택했다. 공개 저장소에는 이 기술 요약과 이어하기 자료를, 전체 사용자·도우미 대화는 별도 비공개 백업에 보관한다.
