# 유지해야 할 요구사항

## 사용자와 수업

- 한국어 PC·태블릿 웹 게임. 중2~고1, 남녀 혼합 20명, 5명씩 4모둠, 약 20~35분.
- 제목 ‘사라진 장인의 보물’, 부제 ‘기록관의 네 봉인’.
- 특별전 개막 전날 봉인된 유물의 기록을 복원하는 이야기. 종이·실·흙·자개의 원리를 이해하여 장인의 기억을 되찾는다.
- 네 방마다 이야기·공예 지식·실제 단서·체험형 퍼즐·성취 결과가 필요하다.

## 필수 퍼즐

- 한지: 한옥 창호·한지등·닥나무·발의 식별 가능한 공간. 디지털 투명지 두 장의 직접 드래그 정렬로만 3을 드러낸 뒤, 한지의 재료·특징 확인 문항.
- 매듭: 국화매듭·가락지매듭·노리개를 참고한 공간. 끈 경로와 네 위아래 교차의 반복·대칭을 조작해 4 획득. 단순 8자 고리 두 개 방식 금지. 도식과 실제 기법 구별.
- 청자: 네 제작 과정 카드를 드래그 정렬. 기물 성형 → 홈 새기기 → 다른 색 흙 채우기 → 표면 정리. 백토·흑토를 알맞게 채우면 2. 실제 제작의 추가 공정 안내.
- 나전: 검은 옻칠 바탕과 자개 광택. 조각을 이동·회전해 여섯 꽃잎의 실제 꽃 완성. 조각낸 숫자 그림 방식 금지. 완성 꽃잎을 세어 6. 꽃잎 수가 게임 규칙임을 안내.

## 공통·교사용 기능

모둠 이름, 이야기 화면, 360도 탐색, 강조된 클릭 단서·편지, 미션 창, 정오답 피드백, 세 단계 힌트, 자동 저장·이어 하기, 타이머, 효과음 전환, 네 자리 자물쇠, 성공 연출·학습 요약, 처음부터 다시 시작을 유지한다.

별도 교사용 화면에는 전체 이야기·진행 대본·정답·조작법·학습 목표·핵심 개념·연습 방 이동·초기화·힌트·4모둠 순환표·출력용 학생 워크시트가 필요하다. 학생 화면에 교사용 답안을 미리 표시하지 않는다.

## 디자인과 전달물

한지의 미색, 매듭의 오방색, 청자의 청록, 나전의 검정과 무지갯빛 광택을 표현한다. 교육 사물과 작품을 알아볼 수 있어야 한다. 실행 가능한 index.html과 리소스, README, 교사 설명서, 워크시트, 전체 프로젝트 ZIP을 제공한다.

네 방 표시, 마우스·터치 회전, 모든 단서, 실제 조작 정답, 오답 통과 방지, 3426 탈출, 저장·이어 하기·초기화, PC·태블릿 배치, 교사·학생 분리를 실제 브라우저에서 확인한다. 실행한 검증과 남은 기기·수업 실증 범위를 명확히 구별한다.
