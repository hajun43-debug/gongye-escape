# 사라진 장인의 보물

**기록관의 네 봉인** — 한국 전통공예 웹 기반 3D 미술 방탈출

중2–고1, 20명(5명씩 4모둠)을 위한 약 20–35분의 협력 게임입니다. 한지·매듭·상감청자·나전칠기 작업실을 360도로 탐색하고, 실제 조작으로 네 기록을 복원합니다.

## GitHub Pages

- 저장소: [hajun43-debug/gongye-escape](https://github.com/hajun43-debug/gongye-escape)
- 게임 주소: [사라진 장인의 보물](https://hajun43-debug.github.io/gongye-escape/) — 공개 게임 실행 주소입니다.
- 배포 설정: 저장소 **Settings → Pages → Deploy from a branch → main → /(root) → Save**.

진입 파일은 저장소 루트의 `index.html`입니다. `.nojekyll` 파일을 포함해 빌드 없이 정적 파일을 배포합니다. 필요한 리소스를 모두 저장소 안에 포함하며, 별도의 API 키나 서버 설정이 필요하지 않습니다. 이후 `main`의 게임 파일을 수정하면 Pages에서 다시 배포됩니다.

교사용 화면은 게임 주소 뒤에 `teacher.html`, 학생 워크시트는 `docs/학생-워크시트.html`을 붙여 엽니다. 교사용 코드는 수업 중 화면 분리용이며 공개 저장소에서의 보안 인증은 아닙니다.

## 실행

### 가장 간단한 방법 — 설치 없이

1. ZIP을 **전체 압축 해제**합니다.
2. `index.html`을 Chrome, Edge, Safari 등 WebGL 지원 브라우저로 엽니다.
3. 모둠 이름을 쓰고 입장합니다.

Three.js, 화면, 퍼즐, 효과음이 모두 프로젝트 안에 있습니다. 외부 이미지·글꼴·CDN·API 호출이 없으므로 **인터넷 없이 실행**할 수 있습니다. `vendor` 폴더를 함께 보관해야 합니다. 실제 브라우저 검증은 아래 HTTP 방식으로 수행했습니다. 내장 검증 브라우저는 파일 주소 열기를 허용하지 않아 더블클릭 방식은 실기 검증하지 못했습니다. 파일 주소의 저장 정책은 브라우저마다 다르므로 안정적인 이어 하기에는 아래 로컬 서버를 권장합니다.

### 권장 방법 — 로컬 서버

Node.js 18 이상이 이미 설치되어 있다면 프로젝트 폴더에서:

```powershell
node server.cjs
```

브라우저에서 `http://127.0.0.1:4173/`을 엽니다. 패키지 설치나 빌드가 필요 없습니다. 서버를 종료하려면 실행한 터미널에서 Ctrl+C를 누릅니다. 서버는 실행 중인 컴퓨터에만 연결됩니다.

태블릿에는 압축 해제된 전체 프로젝트를 복사해 브라우저에서 열거나, 학교에서 승인한 정적 웹 호스팅에 전체 폴더를 올려 같은 주소로 접속하세요. 태블릿에서 PC의 `127.0.0.1`로 접속할 수는 없습니다. 로컬에서 작업한 결과물이며 별도의 온라인 배포는 하지 않았습니다.

## 학생 조작

- 화면을 마우스나 한 손가락으로 끌면 360도로 돌아봅니다. 화면의 좌우 회전 버튼, 캔버스를 선택한 후 방향키도 사용할 수 있습니다.
- 빛나는 표식 또는 **단서 조사** 목록으로 방마다 편지·재료·도구 세 가지를 조사합니다.
- **봉인 복원**에서 손으로 퍼즐을 조작합니다. 정확한 조작과 확인 단계를 통과해야 숫자가 기록됩니다.
- 네 방은 처음부터 자유롭게 이동합니다. 해결하지 못한 방도 이동할 수 있고, 중간 조작이 저장됩니다.
- 방마다 힌트 3단계를 차례로 열 수 있습니다. **복원 수첩**에서 기록과 마지막 자물쇠를 엽니다.
- **소리 끔/켬**으로 Web Audio 효과음을 조절합니다. 기본은 꺼짐입니다.
- **처음부터**를 누르고 확인하면 해당 모드의 기록을 초기화합니다.

태블릿 가로 1024×768 이상을 권장하며 세로 768×1024도 지원합니다. 퍼즐은 비율을 유지해 축소되며 대화창은 스크롤할 수 있습니다. 퍼즐 조작 중에는 화면 회전 대신 퍼즐만 움직입니다. 두 손가락 확대 동작은 구현하지 않았습니다.

## 자동 저장

모둠 이름, 현재 방, 조사한 단서, 힌트 횟수, 봉인 해제, 퍼즐 위치·순서·회전·색 흙, 활성 플레이 시간과 완료 결과를 **같은 브라우저의 localStorage**에 저장합니다. 조작 종료·단서 확인·방 이동 때와 약 5초 간격으로 저장합니다. 재접속하면 시작 화면에 **이어 하기**가 표시됩니다. 탭이 숨겨진 시간과 게임을 닫은 시간은 타이머에 더하지 않습니다. 교사 자료를 보는 별도 탭이 활성화되면 게임 탭의 타이머도 멈춥니다.

기기를 바꾸거나 다른 브라우저·프로필·주소·포트로 접속하면 기록이 공유되지 않습니다. 사생활 보호 모드, 저장소 차단, 브라우저 데이터 삭제 시 이어 하기가 제한됩니다. 저장에 실패하면 화면에 표시됩니다. 카메라 방향은 방 입장 때 기본 시점으로 돌아옵니다.

## 교사용 자료

- `teacher.html`: 입장 코드 **1031**. 정답, 조작 방법, 진행 대본, 학습 목표, 4모둠 순환표, 힌트, 연습용 방 이동 및 선택한 방 초기화.
- `docs/교사용-운영설명서.html`: 출력용 운영 설명서. 브라우저 인쇄로 PDF 저장 가능.
- `docs/학생-워크시트.html`: 정답이 없는 A4 학생 활동지. 브라우저에서 인쇄 또는 PDF 저장.
- `docs/원본분석.md`: 원본 구조 분석과 새 구현에서 달라진 점.
- `docs/테스트결과.md`: 실제 브라우저 검증 결과와 남은 제한 사항.

교사용 연습은 `index.html?practice=1&room=0`(0–3)으로 엽니다. 학생 기록(`artisan-seals-v1`)과 연습 기록(`artisan-seals-practice-v1`)을 분리했습니다. 선택한 방 초기화 전에는 열려 있는 연습 탭을 닫으세요. 교사용 코드는 우발적인 정답 노출을 줄이기 위한 화면 분리이며 보안 인증이 아닙니다. 정적 파일의 소스를 조사하는 학생에게 정답을 비밀로 유지하는 서버 보안 기능은 없습니다.

## 브라우저 검증 재실행

로컬 서버를 실행한 다음 `http://127.0.0.1:4173/tests/browser-tests.html`을 열고 전체 검증 버튼을 누릅니다. 실제 게임을 iframe에 실행하여 조작·오답 방지·저장·이어 하기·완료·초기화·화면 크기를 검사합니다. 연습 기록은 검증 중 새로 작성되므로 사용 중인 연습 탭을 닫아 주세요. 학생 기록은 그대로 유지합니다. 합성한 mouse/touch PointerEvent 검증이며 물리 태블릿 실기 테스트를 대신하지 않습니다.

## 구현과 학습 범위

원본 `고흐미술관/index.html`과 `README.md`는 수정하지 않고 별도 폴더에서 제작했습니다. 원본의 Three.js r128 기반 고정 시점 탐색, Pointer Events, HUD, 단서 창, 숫자 자물쇠 구조를 참고했습니다. 배경은 코드로 새로 만든 실제 3D 기하이며 평면 파노라마가 아닙니다. 특정 유물의 정밀 복제나 실제 공예 제작 전 과정을 재현한 실습은 아닙니다.

매듭 도식은 반복·대칭·교차를 설명하는 교육용 모형입니다. 상감의 네 단계는 장식의 핵심 과정이며 건조·유약·굽기 등의 추가 공정이 있습니다. 꽃잎 수는 게임 규칙입니다. 자개는 스스로 발광하지 않고 빛을 반사합니다. 참고한 공개 공예 자료는 교사용 설명서에 기재했습니다.

Three.js r128: MIT, `vendor/THREE-LICENSE.txt` 참조. 그 외 공간·텍스처·SVG 무늬·효과음·수업 자료는 이 프로젝트를 위해 작성했습니다. 개인 정보 수집, 외부 전송, 분석 추적, 로그인 서버는 없습니다.
