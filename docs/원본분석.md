# 원본 분석과 구현 대응

원본 위치: 작업 폴더의 `고흐미술관/index.html`, `고흐미술관/README.md`. 원본을 읽기만 했으며 변경하지 않았습니다.

## 원본 구조

원본은 단일 HTML 안에 CSS와 JavaScript를 포함한 ‘고흐의 잠긴 아틀리에’입니다. Three.js r128과 웹 글꼴을 CDN에서 불러옵니다. PerspectiveCamera의 yaw/pitch를 Pointer Events로 바꾸고, 시점 범위를 제한하며, 드래그 거리와 시간을 보고 탐색과 클릭을 구별합니다. 장면의 조사 지점은 Raycaster로 판정합니다.

별이 빛나는 밤·해바라기·아를의 침실을 별도 생성 함수로 만들고 HUD, 편지 형태의 modal, Web Audio, 타이머와 localStorage를 공통으로 사용합니다. 자물쇠는 별 11·해바라기 15·의자 2를 모으는 세 항목이며 원본 README는 이를 간단히 안내합니다. 원본의 붓질 셰이더와 미술사 소재는 고흐 주제에 특화되어 있습니다.

## 새 구현

| 요구 | 구현 파일·방식 |
|---|---|
| 원본 보존·새 프로젝트 | 형제 폴더 `사라진-장인의-보물`에 신규 작성 |
| 360도 3D 탐색 | scene.js: 방 전체의 벽·바닥·보·창호·작업대·도구·작품, PerspectiveCamera, 포인터 yaw/pitch |
| 조사 가능한 단서 | 3D 위치를 화면에 투영한 시각 강조 표식 + 동일한 접근성 조사 목록 |
| 한지 직접 정렬 | game.js: SVG 투명지 두 장, 분산 무늬 중첩, 실제 이동과 좌표 검증 후 재료·특징 문항 |
| 매듭 경로·교차 | 두 경로 손잡이와 네 위아래 교차의 조합 판정. 단순 8자 고리 방식 사용 안 함 |
| 상감 체험 | 드래그 삽입으로 네 카드 정렬 후, 백토·흑토를 선택하여 여섯 홈 채우기 |
| 나전 체험 | 꽃잎 여섯 조각을 각각 이동·회전. 위치와 각도가 맞아야 고정. 완성 꽃 관찰 문항 |
| 저장·타이머·소리 | localStorage, 활성 플레이 시간, Web Audio 효과음 |
| 순환 수업 | 처음부터 네 방 자유 이동, 중간 상태 유지, 고정된 최종 암호 순서 |
| 교사 자료·격리 연습 | teacher.html + 별도 연습 저장 키, 방별 초기화 |
| 학생 워크시트 | 정답 없는 별도 출력용 HTML 2쪽 구성 |
| 브라우저 검증 | tests/browser-tests.html에서 실제 게임 iframe 조작·부정 경로 검증 |

원본의 미술 표현과 코드를 그대로 이름만 바꾼 것이 아니라, 3D 자산·공예 퍼즐·상태 구조·한국어 수업 내용을 새로 작성했습니다. raycast에만 의존하지 않고 투영 표식과 단서 목록을 함께 제공해 터치·키보드에서도 조사 지점에 접근할 수 있도록 했습니다. 외부 CDN과 글꼴을 없애고 Three.js를 프로젝트 안에 포함했습니다.
