1. 수업 전 준비

  1. 압축을 전체 해제하고 index.html을 열어 네 작업실이 표시되는지 확인합니다. 가능하면 README의 로컬 서버 방식으로 실행합니다.
  2. 모둠별 기기 1대와 워크시트 1부를 준비합니다. 태블릿은 가로 사용을 권장합니다.
  3. teacher.html에서 연습 화면을 열어 이동·회전·힌트·저장을 확인합니다. 연습은 학생 기록과 분리됩니다.
  4. 전체 화면에 교사 정답 페이지가 비치지 않도록 합니다. 학생에게는 게임 주소만 안내합니다.

2. 전체 이야기

전통공예 특별전 개막 전날 밤, 기록관의 네 유물이 봉인됩니다. 마지막 장인은 후대의 복원가에게 종이·실·흙·자개의 원리를 이해해야 사라진 기록을 되찾을 수 있다고 남깁니다. 학생들은 젊은 복원팀으로 네 작업실을 탐색합니다. 방마다 재료와 도구를 조사하고 손으로 복원하여 기억과 숫자 한 자리를 얻습니다. 마지막 봉인이 열리면 보물은 장인의 지혜와 전승의 가치였음이 드러나고 특별전이 다시 열립니다.

3. 4모둠 순환 운영

도입 3분 → 4회 순환 각 약 5분 → 마지막 자물쇠 2분 → 공유 5분을 권장합니다. 속도 경쟁보다 근거 설명과 협력에 초점을 둡니다. 순환이 끝난 뒤 미완료 방에 돌아가 복원하도록 3–5분을 탄력 운영합니다. 게임은 시간 제한으로 강제 종료되지 않습니다.

4. 교사 진행 대본

도입: “내일 특별전을 열어야 하는데 네 유물의 기록이 사라졌습니다. 여러분은 문화유산 복원팀입니다. 장인의 편지와 재료의 성질을 연결해 기록을 되찾읍시다.”

탐색: “세 사물을 모두 조사하세요. 설명을 읽은 뒤 어떤 조작이 필요한지 팀원에게 말해 보세요. 화면이 돌아가면 마우스나 손가락으로 다시 시점을 맞출 수 있습니다.”

지원: “어떤 단서가 지금 조작의 근거인가요? 해결이 어려우면 힌트를 차례로 열어도 됩니다. 조작자 혼자 결정하지 않고 두 명 이상이 설명해 봅시다.”

전환: “중간 상태가 자동 저장됩니다. 역할을 바꾸고 다음 방으로 갑니다. 미완료 방은 나중에 다시 열 수 있습니다.”

마무리: “보물은 무엇이었나요? 게임의 규칙과 실제 공예 지식을 구분해 설명하고, 한 가지 재료의 새로운 쓰임을 제안해 봅시다.”

5. 방별 정답과 작동 방법

A · 한지공예 / 종이의 방 / 숫자 3

목표: 닥나무 껍질 섬유, 질김, 부드러운 빛 투과의 관계를 설명한다.
조작: 편지·재료·발 세 단서를 조사합니다. 투명지 두 장을 모두 빛판의 같은 점선 틀로 직접 끌어 모서리를 맞춥니다. 겹침 무늬가 3을 드러냅니다. 한 장만 이동하거나 위치가 틀리면 다음 단계로 넘어가지 않습니다. 이어서 닥나무 껍질 섬유와 한지의 특징을 연결한 설명을 고릅니다.
힌트: 두 장 모두 이동 → 점선 모서리에 정렬 → 같은 틀에 겹친 뒤 닥나무와 빛을 연결.

B · 매듭공예 / 실의 방 / 숫자 4

목표: 반복·대칭과 교차의 위아래를 관찰한다. 교육 도식과 실제 전통 기법을 구분한다.
조작: 좌우 손잡이를 같은 높이의 금빛 말뚝에 끌어 놓습니다. 좌상부터 시계 방향으로 교차점 위의 색을 적색 → 금빛 → 적색 → 금빛으로 맞춰 짜임 확인을 누릅니다. 경로와 네 교차를 모두 맞춰야 합니다.
힌트: 양 손잡이를 말뚝으로 → 위에 놓인 색에 주목 → 적·금·적·금 반복.
구별: 국화매듭과 가락지매듭, 노리개는 서로 다른 형태와 쓰임을 관찰하는 참고입니다. 게임 도식은 실제 국화매듭 제작법이 아닙니다.

C · 고려 상감청자 / 흙의 방 / 숫자 2

목표: 상감의 핵심 단계와 다른 색 흙을 채우는 원리를 설명한다.
조작: 카드를 기물 성형 → 무늬 홈 새기기 → 다른 색 흙 채우기 → 표면 정리하기로 드래그 정렬하여 확인합니다. 그다음 꽃 홈 세 곳에는 백토, 줄기 홈 세 곳에는 흑토를 채우고 확인합니다. 틀린 홈은 바른 흙으로 다시 채웁니다.
힌트: 먼저·마지막 찾기 → 성형·홈·채움·정리 → 꽃 백토 / 줄기 흑토.
구별: 네 카드는 상감 장식의 핵심을 추린 것입니다. 실제 청자는 건조·초벌·유약 바르기·재벌구이 등 추가 공정이 필요합니다. 화면의 흑백은 굽기 뒤 무늬를 이해하기 위한 표현입니다.

D · 나전칠기 / 빛의 방 / 숫자 6

목표: 자개와 옻칠 바탕의 대비, 반사 광택, 꽃의 회전 대칭을 관찰한다.
조작: 조각 선택 → ±30° 회전 또는 R 키 → 점선 꽃잎 중심으로 이동. 위쪽부터 시계 방향으로 각 조각은 0·60·120·180·240·300° 방향입니다. 위치와 회전이 모두 맞으면 고정됩니다. 실제 여섯 꽃잎의 꽃이 완성된 뒤 꽃잎 수 6을 입력합니다.
힌트: 긴 끝은 바깥 → 위치와 회전을 모두 확인 → 60도 간격의 여섯 방향, 완성 후 세기.
구별: 꽃잎 수는 이번 게임 규칙입니다. 모든 전통 문양의 고정된 꽃잎 수를 말하지 않습니다. 자개는 스스로 발광하지 않고 받은 빛을 반사합니다.

6. 테스트와 초기화

teacher.html의 연습 링크에서 원하는 방으로 새 게임을 시작할 수 있습니다. 연습 저장은 학생 저장과 분리됩니다. 특정 방만 초기화하려면 연습 탭을 닫고 교사용 화면에서 방을 선택해 초기화한 뒤, 연습 화면을 다시 열어 이어 하기를 누릅니다. 연습 게임 자체의 ‘처음부터’는 연습 전체를 초기화합니다. 교사용 코드 1031은 실수로 정답을 열지 않게 하는 구분이며 서버 보안 인증은 아닙니다.

모둠 기록은 같은 기기·브라우저·주소에서 유지됩니다. 새로고침과 재접속 후 이어 하기를 사용합니다. 탭을 숨기면 타이머가 멈춥니다. 저장 실패 표시가 나오면 창을 유지하고 활동지를 활용하세요. 다른 기기로 동기화하거나 교사가 여러 모둠의 상태를 원격으로 모니터링하는 기능은 없습니다.
