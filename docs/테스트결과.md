# 실제 실행 검증 결과

검증일: 2026-10-31 (한국 시간). 원본을 보존하고 새 프로젝트를 구현한 뒤 실제 브라우저에서 실행했습니다.

## 실행 환경과 방법

- Node.js v24.22.1, 프로젝트의 `node server.cjs`로 로컬 HTTP 실행.
- Codex 내장 브라우저에서 게임을 직접 열어 시각 확인, 실제 마우스 드래그 및 단서 표식 클릭.
- `tests/browser-tests.html`의 실제 게임 iframe에서 합성 mouse/touch PointerEvent, 버튼·폼 입력을 사용한 통합 검증.
- 검증은 별도 교사용 연습 키에서 수행. 최종 회귀 검증 **56 / 56 통과**.
- 화면 크기: PC 1440×900, 태블릿 가로 1024×768 및 세로 768×1024. 통합 검증의 iframe 크기 검사와 별도 탭의 실제 뷰포트 수동 확인을 함께 수행.
- 원시 결과: `screenshots/browser-tests.json`. 실제 실행 화면: `screenshots/`의 JPG.

## 추가 수동 검증과 수정

- 한지 무늬는 실제 2분할 중첩 패턴입니다. 숫자를 그린 마스크의 영역에서 두 무늬의 점이 보완되어 숫자 3이 드러납니다. 화면 축소 시 보간으로 무늬가 뭉개지는 문제를 발견하여 `image-rendering: pixelated`를 적용하고 중첩 결과의 가독성을 다시 확인했습니다.
- 자개 꽃을 옻칠함 앞면에도 배치하여 기본 시점에서 보이도록 수정했습니다. 꽃잎은 번호가 아니라 모양과 각도가 맞는 빈자리에 놓일 수 있습니다.
- 드래그 취소 시 원래 위치로 돌아가도록 하고, 새 게임 타이머 저장 간격도 다시 시작하도록 보완했습니다.
- 교사용 연습 방 지정 출발, 선택 방 초기화, 코드 오답 피드백을 직접 확인했습니다.
- 학생 워크시트와 교사용 운영 설명서의 별도 페이지 표시, 출력용 스타일과 학생 활동지의 정답 비노출 구성을 확인했습니다.
- 최종 소스의 `node --check`를 통과했습니다. Three.js r128과 MIT 라이선스를 로컬에 포함했습니다.

## 남은 제한 사항

1. **실물 태블릿 터치 실기는 수행하지 않았습니다.** 터치는 실제 브라우저 내부의 합성 PointerEvent로 검증했고, 태블릿 크기의 화면은 실제 뷰포트와 iframe에서 확인했습니다. Safari·iPadOS·Android 기기별 교차 검증은 남아 있습니다.
2. 20–35분은 수업 운영 목표입니다. 실제 20명 학급으로 소요 시간과 난도를 실증한 결과는 아닙니다. 교사 설명, 역할 순환, 워크시트 토의를 포함해 첫 수업에서 조정하세요.
3. 입체 공간은 절차적으로 만든 교육용 표현입니다. 특정 문화유산의 정밀 3D 복제품, 실제 매듭 전 과정이나 도자기 소성 시뮬레이션은 아닙니다. 매듭·상감·꽃잎 수의 단순화는 게임과 교사 자료에 명시했습니다.
4. 교사용 코드는 화면 분리용입니다. 정적 클라이언트 소스를 조사하는 사용자의 정답 접근까지 막는 인증 시스템은 아닙니다.
5. 저장은 같은 브라우저·주소의 localStorage에 한정됩니다. 기기 간 동기화·교사 원격 대시보드·중앙 서버는 없습니다. 저장 차단 또는 브라우저 데이터 삭제 시 기록을 유지할 수 없습니다. 카메라 방향은 저장하지 않습니다.
6. WebGL이 필요한 3D 화면입니다. WebGL을 사용할 수 없으면 오류 안내와 조사 목록을 제공합니다. 두 손가락 확대·이동식 1인칭 보행은 구현하지 않았습니다.
7. 자료는 출력 가능한 HTML입니다. 브라우저의 인쇄 또는 PDF 저장을 사용할 수 있으며, 별도 PDF 파일이나 실제 프린터 출력 실기는 포함하지 않았습니다.
8. 새 로컬 프로젝트와 ZIP을 제공하며 온라인 서비스로 배포하지 않았습니다. 실제 실행 검증은 로컬 HTTP 방식으로 수행했습니다. 내장 브라우저의 URL 보안 정책이 `file:` 주소 열기를 차단하여 파일 더블클릭 방식은 이 환경에서 검증하지 못했습니다. 우회하지 않았으며, 검증된 실행 경로는 README의 `node server.cjs` 방식입니다. 파일 주소의 저장 정책도 브라우저별로 다를 수 있어 수업에는 고정 HTTP 주소를 권장합니다.
