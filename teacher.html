수업 운영 한눈에 보기

중2–고1 · 20명 · 5명씩 4모둠 · 게임 20–35분. 도입 3분, 방별 활동 약 5분씩 4회, 최종 봉인 2분, 공유 5분으로 약 30분을 권장합니다. 읽기·조작 속도에 따라 달라지므로 첫 수업 후 시간을 조정하세요.

각 모둠에 기기 한 대를 배정하고 탐색자·조작자·기록자·해석자·시간관리자를 정합니다. 방을 바꿀 때 역할도 바꿉니다. 카메라 조작이 어려우면 조사 목록을 활용할 수 있습니다.

모둠1회2회3회4회
1종이실흙빛
2실흙빛종이

방은 처음부터 모두 이동 가능합니다. 5분마다 다음 방으로 이동하고, 미완료 퍼즐은 자동 저장하여 자유 복원 시간에 다시 엽니다. 최종 기록은 입장 순서와 무관하게 종이 → 실 → 흙 → 빛으로 정리합니다.

정답과 퍼즐 작동 방법

방조작과 정답학습 목표
한지 · 3단서 3개 조사 → 투명지 두 장 모두 중앙 빛판 틀에 이동. 왼쪽 위 (270,78), 오차 7 단위 이내. 중첩 무늬는 3. 확인 문항은 닥나무 껍질 섬유·질김·빛의 부드러운 투과.한지의 주재료와 성질을 쓰임에 연결한다.
매듭 · 4양 손잡이를 좌우 말뚝(180,180), (540,180)에 이동. 좌상부터 시계 방향으로 적색 위 / 금빛 위 / 적색 위 / 금빛 위. 네 교차 모두 맞춰 확인.경로, 반복, 대칭, 위아래 교차를 구별한다. 실제 전통매듭 제작법과 교육 도식을 구분한다.
청자 · 2기물 성형 → 무늬 홈 새기기 → 다른 색 흙 채우기 → 표면 정리하기. 그다음 꽃 홈 3곳은 백토, 줄기 홈 3곳은 흑토로 채우고 확인.상감의 핵심 과정과 다른 색 흙을 채우는 원리를 설명한다. 실제 청자는 추가 공정이 있음을 안다.
나전 · 6조각을 선택하고 ±30° 버튼 또는 R로 회전 → 점선 꽃잎 자리에 이동. 각 조각의 방향은 위에서 시계 방향으로 0·60·120·180·240·300°. 6개가 고정된 뒤 꽃잎 수 6 입력.자개와 옻칠 바탕의 대비·반사 광택을 이해한다. 꽃잎 수는 게임 규칙임을 구분한다.

최종 암호: 3426 · 종이 → 실 → 흙 → 빛

테스트용 방 이동 · 초기화

아래 링크는 학생 기록과 분리된 교사용 연습을 엽니다. 처음 시작하면 선택한 방에서 출발합니다. 기존 연습을 이어 하면 마지막 연습 위치를 불러옵니다. 연습 화면의 ‘처음부터’로 전체를 초기화하거나 아래에서 방 하나만 초기화하세요.

초기화 전 연습 탭을 닫고 실행하세요. 다시 열 때 ‘이어 하기’를 누릅니다. 학생 저장 키는 수정하지 않습니다.

교사 진행 대본

도입 “내일 특별전을 열어야 하는데 네 유물의 기록이 봉인되었습니다. 여러분은 젊은 문화유산 복원팀입니다. 장인의 편지를 읽고, 재료와 도구가 알려 주는 원리를 함께 찾아봅시다.”

탐색 시작 “빛나는 표식을 눌러 단서를 모으세요. 정답을 추측하기 전에 모든 재료와 도구를 조사합니다. 조작자는 팀의 설명을 듣고 손을 움직이고, 기록자는 근거를 남깁니다.”

막혔을 때 “어느 단서가 이 조작과 연결되나요? 두 사람의 설명을 비교해 보세요. 필요하면 힌트 1부터 차례로 열어도 됩니다.”

전환 “지금 상태는 자동으로 저장됩니다. 역할을 바꾸고 다음 작업실로 이동하세요. 못 푼 방은 나중에 돌아올 수 있습니다.”

마무리 “장인이 남긴 보물은 무엇이었을까요? 게임의 규칙과 실제 공예 지식을 구분해 설명하고, 네 재료 중 하나를 골라 새로운 쓰임을 제안해 봅시다.”

단계별 힌트

  1. 한지: 두 장 모두 빛판으로 → 왼쪽 위 모서리를 점선에 → 같은 틀에 정확히 포개고 닥나무와 빛의 성질을 연결.
  2. 매듭: 양 손잡이를 말뚝으로 → 위에 놓인 색을 관찰 → 좌상부터 적·금·적·금.
  3. 청자: 먼저·마지막 찾기 → 성형·홈·채움·정리 → 꽃은 백토, 줄기는 흑토.
  4. 나전: 긴 끝은 바깥 → 위치뿐 아니라 회전 확인 → 60도 간격의 여섯 방향으로 배치 후 꽃잎 세기.

관찰과 평가

완료 속도보다 단서에 근거한 설명, 협력과 역할 순환, 공예 개념의 정확성을 확인합니다. “상감은 물감으로 그리는 것인가?”, “이 도식만으로 실제 국화매듭을 만들 수 있는가?”, “자개는 스스로 빛을 내는가?”, “여섯 꽃잎은 역사적 규칙인가?”를 짧게 토의합니다.
